Planning documents your coding agent can trust

Describe what you want to build. ARK finds the official docs, scrapes them, and writes a plan that cites every claim back to the page it came from.

generate $ ark docs "build a RAG service over PDFs" --plan
browse $ npx ark-plans list
use $ npx ark-plans add <slug>
