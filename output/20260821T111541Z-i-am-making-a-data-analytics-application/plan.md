## Pitfalls

- NumPy 2.5.0 requires Python 3.9+; using an older interpreter will fail.
- Calling `np.random.default_rng()` repeatedly creates independent generators; seed once and reuse for reproducibility.
- Reshaping demands the total element count match; mismatched sizes raise a ValueError.
- Very large arrays can exhaust memory; keep sample sizes reasonable for the target environment.
- `ndarray.max(axis=1)` returns a new array; modifying it does not affect the original data.
- If the virtual environment is not activated, `pip install` may affect the global Python environment.
