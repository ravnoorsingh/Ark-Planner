### Phase 1 — Initialize project and add dependencies

- Run `uv init myapi --bare` to create a minimal pyproject.toml[^fastapi-1]
- Add FastAPI with standard extras: `uv add "fastapi[standard]"`[^fastapi-1]
- Add Uvicorn server: `uv add uvicorn`[^uvicorn-1]
- Commit the generated pyproject.toml to version control
- Create a `src/` directory and place code under `src/` to match the module layout
- Ensure the Python interpreter version is compatible with FastAPI and Pydantic (>=3.9)

### Phase 2 — Create FastAPI application skeleton

- Create file `src/main.py`
- Import FastAPI: `from fastapi import FastAPI`[^fastapi-1]
- Instantiate the app: `app = FastAPI()`
- Add a simple health endpoint: `@app.get("/health")\n    def health():\n        return {"status": "ok"}`
- Export the app variable for uvicorn: `__all__ = ["app"]`
- Run a dev server to verify: `uv run fastapi dev`[^fastapi-1]

### Phase 3 — Define Pydantic data models

- In `src/models.py` import BaseModel: `from pydantic import BaseModel, PositiveInt`[^pydantic-1]
- Create a request model, e.g., `class ItemCreate(BaseModel):\n    name: str\n    quantity: PositiveInt`
- Create a response model, e.g., `class ItemResponse(BaseModel):\n    id: int\n    name: str\n    quantity: int\n    created_at: datetime | None`
- Use `model_dump()` when serializing models in responses[^pydantic-1]
- Add `__all__` export for the models
- Run a quick script to instantiate the models and print `model_dump()` to confirm validation

### Phase 4 — Implement CRUD routes

- In `src/main.py` import the models: `from .models import ItemCreate, ItemResponse`[^pydantic-1]
- Add a POST route: `@app.post("/items", response_model=ItemResponse)`\n    `def create_item(item: ItemCreate):\n        # placeholder logic, assign id and timestamp\n        return ItemResponse(id=1, name=item.name, quantity=item.quantity, created_at=None)`

## Pitfalls

- Using `fastapi dev` in production will run the server in watch mode; switch to `fastapi run` for stable deployments[^fastapi-1]
- If you install FastAPI without the `[standard]` extras you may miss optional dependencies like `email-validator` required for some features[^fastapi-1]
- The `uvicorn.workers.UvicornWorker` module is deprecated; avoid it and use the `fastapi run` command or the `uvicorn-worker` package for Gunicorn integration[^uvicorn-1]
- Pydantic V2 introduces breaking changes; ensure your code follows V2 syntax or import `pydantic_v1` if you need legacy behavior[^pydantic-1]
- Running `uv add uvicorn` installs the server but does not automatically add the optional `uvicorn-worker` package needed for Gunicorn; add it separately if you plan to use Gunicorn[^uvicorn-1]
- Make sure the Python version in the `uv` environment satisfies FastAPI and Pydantic requirements (>=3.9); otherwise import errors will occur
