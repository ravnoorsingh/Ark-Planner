## Implementation

### Phase 1 — Project Setup

- Initialize a new project directory and version control.
- Add FastAPI with standard extras via `uv add "fastapi[standard]"`[^fastapi-1].
- Add python-multipart via `uv add multipart`[^python-multipart-1].
- Install pypdf, sentence-transformers, faiss-cpu, and numpy using pip or conda as documented[^pypdf-1][^sentence-transformers-1][^faiss-cpu-1][^numpy-1].
- Create `main.py` as the entry point.
- Record dependencies in `pyproject.toml` or `requirements.txt`.

### Phase 2 — API Skeleton

- Import FastAPI and instantiate `app = FastAPI()`[^fastapi-1].
- Define a GET `/health` endpoint returning `{"status":"ok"}`.
- Define an async POST `/extract` endpoint accepting `file: UploadFile = File(...)`[^python-multipart-1].
- Ensure the endpoint reads the file with `await file.read()`.
- Return a JSON payload with a placeholder for extracted text.
- Add `if __name__ == "__main__": uvicorn.run("main:app", port=8000, log_level="info")`[^uvicorn-1].

### Phase 3 — PDF Extraction

- Write a helper `def extract_text_from_pdf(data: bytes) -> str:`.
- Inside the helper, create a `BytesIO` stream and instantiate `PdfReader` from pypdf[^pypdf-1].
- Iterate over `reader.pages`, call `page.extract_text()`, and concatenate non‑None results.
- Return the combined string; raise HTTPException if no text is found.
- Call this helper from the `/extract` endpoint and include the result in the response.
- Add appropriate imports from `pypdf` and `io`.

### Phase 4 — Embedding Service

- At module load, create a global `model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")`[^sentence-transformers-1].
- Implement `def embed_texts(texts: List[str]) -> np.ndarray:` that returns `model.encode(texts, convert_to_numpy=True)`[^numpy-1].
- Add a POST `/rank` endpoint receiving JSON with `job_description: str` and `resumes: List[str]`.
- Inside the endpoint, compute `job_emb = embed_texts([job_description])` and `resume_emb = embed_texts(resumes)`.
- Store embeddings in memory for the ranking step.
- Return a response confirming embeddings were generated.

### Phase 5 — Similarity Index & Ranking

- Import FAISS and create an index: `index = faiss.IndexFlatL2(job_emb.shape[1])`[^faiss-cpu-1].
- Add resume embeddings to the index via `index.add(resume_emb)`.
- Perform a search: `distances, ids = index.search(job_emb, k=len(resumes))`.
- Convert L2 distances to similarity scores (e.g., `scores = -distances.squeeze()`).
- Build a ranked list of resumes with their scores and return it in the `/rank` response.
- Validate that the dimension of `job_emb` matches the index dimension; raise an error otherwise.

### Phase 6 — Run & Verify

- Start the service in development mode with `uv run fastapi dev`[^fastapi-1].
- Use `curl -F "file=@sample.pdf" http://localhost:8000/extract` to test PDF extraction.
- POST a JSON payload to `/rank` containing a job description and the extracted resume texts; verify the returned order reflects relevance.
- Add basic logging statements for each request.
- Document the startup command and required environment variables in a README.
- Commit all code and ensure the test commands pass.

## Pitfalls

- Missing quotes around "fastapi[standard]" in the `uv add` command will cause installation errors[^fastapi-1].
- Defining the endpoint with `def` instead of `async def` while using `await file.read()` blocks the event loop[^fastapi-1].
- `page.extract_text()` can return `None` for scanned PDFs; filter out None values to avoid empty strings[^pypdf-1].
- Sentence‑Transformer models need PyTorch 2.2+; absence of a compatible torch version raises import errors[^sentence-transformers-1].
- FAISS‑CPU is only distributed via conda; installing it with pip may lead to missing native libraries[^faiss-cpu-1].
- Large PDF uploads may exhaust memory; consider imposing size limits or streaming processing.
