## Library reference

### typer [^typer-1] [^typer-2]

Typer is a library for building CLI applications that users will love using and developers will love creating. It is based on Python type hints and also provides a `typer` command to run scripts, automatically converting them to CLI applications.

**`(main)`**

```
typer.run(main)
```

**`()`**

```
app = typer.Typer()
```

**`()`**

```
@app.command()
```

### rich [^rich-1] [^rich-2]

Rich is a Python library for *rich* text and beautiful formatting in the terminal. The Rich API makes it easy to add color and style to terminal output. Rich can also render pretty tables, progress bars, markdown, syntax highlighted source code, tracebacks, and more — out of the box.

**`rich.print`**

```
from rich import print

print("Hello, [bold magenta]World[/bold magenta]!", ":vampire:", locals())
```

**`rich.pretty.install`**

```
>>> from rich import pretty
>>> pretty.install()
```

**`rich.console.Console`**

```
from rich.console import Console

console = Console()
```

**`Console.print`**

```
console.print("Hello", "World!")
```

**`Console.print (style)`**

```
console.print("Hello", "World!", style="bold red")
```

## Pitfalls

- You must install `uv` first before using `uv add typer`.
- Auto‑completion works only when you create a Python package and run with `--install-completion` or when you use the `typer` command.
- Rich requires Python 3.8 or later.
- True color / emoji works only in the new Windows Terminal; classic Windows terminals are limited to 16 colors.
- Rich works with Jupyter notebooks with no additional configuration required.
