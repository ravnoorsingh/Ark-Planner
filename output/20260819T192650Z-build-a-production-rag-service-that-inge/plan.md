### weaviate-client [^weaviate-client-1] [^weaviate-client-2]

The weaviate-client is the official Python SDK for the Weaviate vector search engine. It provides a synchronous API via the `WeaviateClient` class and an asynchronous API via the `WeaviateAsyncClient` class (available from v4.7.0). The client enables connecting to Weaviate, managing collections, batch importing objects, and performing vector searches.

### python-multipart [^python-multipart-1]

Python-Multipart is a streaming multipart parser for Python. The following example shows a quick example of parsing an incoming request body in a simple WSGI application.

**`python_multipart.parse_form`**

```
import python_multipart
def simple_app(environ, start_response):
    ret = []
    def on_field(field):
        ret.append(b"Parsed value parameter named: %s" % (field.field_name,))
    def on_file(file):
        ret.append(b"Parsed file parameter named: %s" % (file.field_name,))
    headers = {'Content-Type': environ['CONTENT_TYPE']}
    if 'CONTENT_LENGTH' in environ:
        headers['Content-Length'] = environ['CONTENT_LENGTH']
    python_multipart.parse_form(headers, environ['wsgi.input'], on_field, on_file)
    start_response('200 OK', [('Content-type', 'text/plain')])
    ret.append(b'\n')
    return ret
```

**`(boundary, callbacks)`**

```
import hashlib
import python_multipart
from python_multipart.multipart import parse_options_header

def simple_app(environ, start_response):
    ret = []
    class g(object):
        hash = None
    def on_part_begin():
        g.hash = hashlib.sha256()
    def on_part_data(data, start, end):
        g.hash.update(data[start:end])
    def on_part_end():
        ret.append("Part hash: %s" % (g.hash.hexdigest(),))
    content_type, params = parse_options_header(environ['CONTENT_TYPE'])
    boundary = params.get(b'boundary')
    callbacks = {
        'on_part_begin': on_part_begin,
        'on_part_data': on_part_data,
        'on_part_end': on_part_end,
    }
    parser = python_multipart.MultipartParser(boundary, callbacks)
    inp = environ['wsgi.input']
    size = int(environ['CONTENT_LENGTH'])
    while size > 0:
        to_read = min(size, 1024 * 1024)
        data = inp.read(to_read)
        parser.write(data)
        size -= len(data)
        if len(data) != to_read:
            break
    start_response('200 OK', [('Content-type', 'text/plain')])
    return ret
```

## Pitfalls

- If you don't want optional standard dependencies, install with `uv add fastapi` instead of `uv add "fastapi[standard]"`.
- The v4 Python client requires Weaviate v1.23.7 or later; older database versions are incompatible.
- A gRPC port (default 50051) must be open on the Weaviate server for the client to function.
- In Weaviate Cloud, clusters created before 31 January 2024 are not compatible with the v4 client.
- When using Configure.Vectors.text2vec_xxx in client versions 4.16.0‑4.16.3, an error is thrown if no properties are defined and vectorize_collection_name is not True; this is fixed in 4.16.4.
- To use the Query Agent, install the optional extras with `pip install -U "weaviate-client[agents]"`.
- The asynchronous API is provided by the WeaviateAsyncClient class and requires weaviate-client v4.7.0 or newer.
- Requires Python 3.10+, PyTorch 2.2+, and transformers v5.0+ as recommended dependencies.
- Installation uses a pip upgrade command; see the docs for uv, conda, source, editable installs, CUDA setup, and optional extras such as [image], [audio], [video], [train], [onnx], [openvino], [dev].
- Version 6.0 introduced the MultiVectorEncoder for token‑level (multi‑vector) embeddings; migration may require following the migration guide.
- `pypdf` 3.1.0 and above include significant improvements compared to previous versions; refer to the migration guide for details.
- For AES encryption or decryption you must install the extra dependencies with `pip install pypdf[crypto]`.
- Use `print(pypdf.__version__)` to report the library version when filing issues.
- This package used to be accessed via `import multipart`. This still works for now (with a warning) as long as the Python package `multipart` is not also installed. If both are installed, you need to use the full PyPI name `python_multipart` for this package.
