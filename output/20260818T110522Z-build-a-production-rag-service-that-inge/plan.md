## Implementation

### Phase 1 — Project initialization and dependencies

- Create project root and `pyproject.toml`.
- Add FastAPI with standard extras: `uv add "fastapi[standard]"`[^fastapi-1].
- Install pypdf: `pip install pypdf`[^pypdf-1].
- Install Pinecone SDK with asyncio extras: `pip install "pinecone[asyncio]"`[^pinecone-client-1].
- Install uvicorn for ASGI serving: `uv add uvicorn`[^uvicorn-1].
- Add LangChain and Pydantic to dependencies (both are mentioned libraries).

### Phase 2 — Configure Pinecone vector store

- Import `Pinecone` and instantiate with API key: `pc = Pinecone(api_key="YOUR_API_KEY")`[^pinecone-client-1].
- Create a serverless index named `rag-manuals` with dimension 1536 and cosine metric using `ServerlessSpec`[^pinecone-client-1].
- Set `pool_threads` and `connection_pool_maxsize` on the index client for performance as recommended[^pinecone-client-1].

### Phase 3 — PDF ingestion and embedding pipeline

- Write `load_pdf(path: str) -> List[Tuple[str, int]]` that opens a PDF with `PdfReader` and extracts text per page[^pypdf-1].
- For each page, create a chunk tuple `(text, page_number)`.
- Use LangChain to obtain embeddings for each chunk (e.g., `Embeddings` class) – cite LangChain docs[^langchain-1].
- Upsert each embedding to Pinecone with metadata `{"source": filename, "page": page_number}` using `IndexAsyncio.upsert_records`[^pinecone-client-1].

### Phase 4 — Build LangChain retrieval chain

- Initialize a Pinecone vector store wrapper compatible with LangChain.
- Create a `RetrievalQA` chain that queries the Pinecone index and returns documents with metadata[^langchain-1].
- Ensure the chain returns the original page number for citation.

### Phase 5 — FastAPI service with streaming answers

- Instantiate FastAPI: `app = FastAPI()`[^fastapi-1].
- Define health endpoint: `@app.get("/health") async def health(): return {"status": "ok"}`[^fastapi-1].
- Create Pydantic request model `QueryRequest(BaseModel): query: str`[^pydantic-1].
- Create response model `AnswerResponse(BaseModel): answer: str; citations: List[dict]`[^pydantic-1].
- Implement async `/ask` POST endpoint that receives `QueryRequest`, calls the LangChain chain, and streams the answer via `StreamingResponse` while yielding citation data[^fastapi-1].
- Add exception handling for missing index or PDF load errors.

### Phase 6 — Run, test, and verify

- Start server in development mode: `uv run fastapi dev` (auto‑reload) or production: `uvicorn.run("main:app", port=8000)`[^fastapi-1][^uvicorn-1].
- Verify `/health` returns `{"status":"ok"}`.
- Load a sample PDF via the ingestion script and confirm vectors appear in Pinecone.
- Call `/ask` with a sample question; ensure the streamed answer includes a `citations` list referencing correct source file and page.
- Monitor logs for any Pinecone connection pool warnings.

## Pitfalls

- FastAPI must be installed as `fastapi[standard]` in quotes; otherwise uv may fail to resolve extras[^fastapi-1].
- pypdf 3.1.0 defaults `strict=False`; setting it to True can raise unnecessary warnings[^pypdf-3].
- When using the Pinecone SDK without gRPC extras, you must configure `pool_threads` and `connection_pool_maxsize` for good performance[^pinecone-client-1].
- Async FastAPI routes require `async def`; using regular def will block the event loop[^fastapi-1].
- Pydantic V2 changes model field definitions; ensure you import from `pydantic` not `pydantic.v1` unless compatibility is needed[^pydantic-2].
- The `uvicorn.workers` module is deprecated; avoid using it for production deployments[^uvicorn-2].
