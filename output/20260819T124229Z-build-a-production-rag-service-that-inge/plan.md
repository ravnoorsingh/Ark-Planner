### pypdf [^pypdf-1] [^pypdf-2] [^pypdf-3]

pypdf is a free and open source pure‑python PDF library capable of splitting, merging, cropping, and transforming the pages of PDF files. It can also add custom data, viewing options, and passwords to PDF files, and retrieve text and metadata from PDFs.

**`PdfReader(stream : [str] | [IO] [ [Any] ] | [Path] , strict : [bool] = False , password : [str] | [bytes] | [None] = None , * , root_object_recovery_limit : [int] | [None] = 10000 )`**

Initialize a PdfReader object. This operation can take some time, as the PDF stream’s cross‑reference tables are read into memory.

```

reader = PdfReader("example.pdf")number_of_pages = len(reader.pages)page = reader.pages[0]text = page.extract_text()
```

**`close() → None`**

Close the stream if opened in __init__ and clear memory.

**`root_object`**

Provide access to “/Root”. Standardized with PdfWriter.

**`pdf_header`**

### sentence-transformers [^sentence-transformers-1] [^sentence-transformers-2]

Sentence Transformers (SBERT) is a Python library for computing and training state‑of‑the‑art embedding and reranker models. It supports text, image, audio, and video embeddings, similarity scoring with Cross‑Encoders, sparse embeddings, and token‑level multi‑vector embeddings for retrieval.

**`SentenceTransformer`**

Class for loading a pretrained embedding model and computing embeddings.

```

# 1. Load a pretrained Sentence Transformer modelmodel = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

# The sentences to encodesentences = [
    "The weather is lovely today.",
    "It's so sunny outside!",
    "He drove to the stadium.",]

# 2. Calculate embeddings by calling model.encode()embeddings = model.encode(sentences)print(embeddings.shape)# [3, 384]

# 3. Calculate the embedding similaritiessimilarities = model.similarity(embeddings, embeddings)print(similarities)# tensor([[1.0000, 0.6660, 0.1046],#         [0.6660, 1.0000, 0.1411],#         [0.1046, 0.1411, 1.0000]])
```

    "In 2013 around 600,000 Berliners were registered in one of the more than 2,300 sport and fi

- Import `PdfReader` from pypdf[^pypdf-1].

- Implement a simple splitter that breaks each page text into chunks of ~500 characters without breaking words, preserving the original `page` number in each chunk.
- Add a utility `save_chunks(chunks, output_path)` to serialize chunks as JSON for debugging.

### Phase 3 — Embedding generation and Milvus storage

- Create `app/vector_store.py`.
- Import `SentenceTransformer` from sentence_transformers[^sentence-transformers-1] and instantiate `model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")`.
- Import `MilvusClient` from pymilvus[^pymilvus-1].
- Initialize `client = MilvusClient("http://localhost:19530")`[^pymilvus-1].
- Write `embed_chunks(chunks)` that extracts the `text` field, calls `model.encode(texts, batch_size=32)` and returns a list of embeddings.
- Write `create_collection()` that uses `client.create_collection` (assumed API) with a vector field of dimension matching the model output and a scalar field for `page` and `source` metadata.
- Write `insert_embeddings(embeddings, chunks)` that pairs each embedding with its metadata and calls `client.insert` to store them.
- Add a convenience `setup_vector_store(pdf_path)` that loads, chunks, embeds, creates collection, and inserts data.

### Phase 4 — Pydantic request/response models

- Import `BaseModel` from pydantic[^pydantic-1].

    page: int`.
- Define `AnswerChunk(BaseModel): answer: str

- Ensure models are used in FastAPI endpoints for automatic validation.

### Phase 5 — FastAPI application with streaming answer endpoint

- Create `app/main.py`.
- Import `FastAPI` and instantiate `app = FastAPI()`[^fastapi-1].
- Add a health check route `@app.get("/health") async def health(): return {"status": "ok"}`[^fastapi-1].
- Import request/response schemas from `app.schemas`.
- Implement an async generator `async def stream_answer(question: str)` that:
  1. Retrieves relevant vectors from Milvus via `client.search` (assumed API).
  2. Concatenates retrieved texts, forms a prompt, and (placeholder) generates an answer string.
  3. Yields partial answer strings interleaved with citation JSON objects.
- Define endpoint `@app.post("/query") async def query(req: QueryRequest): return StreamingResponse(stream_answer(req.question), media_type="application/json")` using FastAPI's async capability[^fastapi-1].

## Pitfalls

- Milvus collection creation and search APIs are not detailed in the provided brief, so exact method signatures may differ.
- StreamingResponse is part of FastAPI's response utilities but not explicitly covered; ensure the async generator returns properly formatted JSON strings.
- Chunk size and overlap logic are custom; overly large chunks may exceed model token limits.
- Sentence‑Transformer model loading may require additional PyTorch dependencies not listed in the briefs.
- pypdf strict mode defaults to False; encrypted PDFs need extra crypto extras not installed.
- Running Milvus locally requires protobuf and grpcio-tools installations per the Milvus gotchas.
