### pydantic [^pydantic-1] [^pydantic-2] [^pydantic-3]

Pydantic is the most widely used data validation library for Python. Define how data should be in pure, canonical Python 3.10+; validate it with Pydantic. Models are defined by inheriting from BaseModel.

**`pydantic.BaseModel`**

Base class for defining data models with validation.

```
```
from pydantic import BaseModel, ConfigDict

class User(BaseModel):
  id: int
  name: str = 'Jane Doe'

  model_config = ConfigDict(str_max_length=10)
```
```

**`pydantic.ConfigDict`**

Configuration class for customizing BaseModel behavior.

```
```
from pydantic import BaseModel, ConfigDict

class User(BaseModel):
  id: int
  name: str = 'Jane Doe'

  model_config = ConfigDict(str_max_length=10)
```
```

### uvicorn [^uvicorn-1]

Uvicorn is an ASGI web server implementation for Python. Uvicorn currently supports HTTP/1.1 and WebSockets.

**`uvicorn.run`**

Programmatic equivalent of the uvicorn command line interface.

```
import uvicorn

async def app(scope, receive, send):
    ...

if __name__ == "__main__":
    uvicorn.run("main:app", port=5000, log_level="info")
```

**`uvicorn.Config`**

Configuration class for Uvicorn server.

```
import uvicorn

async def app(scope, receive, send):
    ...

if __name__ == "__main__":
    config = uvicorn.Config("main:app", port=5000, log_level="info")
    server = uvicorn.Server(config)
    server.run()
```

**`uvicorn.Server`**

Server class to run Uvicorn with a Config.

```
import uvicorn

async def app(scope, receive, send):
    ...

if __name__ == "__main__":
    config = uvicorn.Config("main:app", port=5000, log_level="info")
    server = uvicorn.Server(config)
    server.run()
```

**`uvicorn.Server.serve`**

Run the server in an already running async environment.

```
import asyncioimport uvicorn

async def app(scope, receive, send):
    ...

async def main():
    config = uvicorn.Config("main:app", port=5000, log_level="info")
    server = uvicorn.Server(config)
    await server.serve()

if __name__ == "__main__":
    asyncio.run(main())
```

**`uvicorn.workers.UvicornWorker`**

Gunicorn worker class for Uvicorn (deprecated).

```
gunicorn example:app -w 4 -k uvicorn.workers.UvicornWorker
```

**`uvicorn`**

Command line tool to run ASGI applications.

```
uvicorn main:app
```

## Pitfalls

- Running in development mode, for production use: fastapi run
- `uvx` is an alias for `uv tool run`
- The `uvicorn.workers` module is deprecated and will be removed in a future release; use the `uvicorn-worker` package instead.
- Install the `uvicorn-worker` package (`python -m pip install uvicorn-worker`) when using Gunicorn with Uvicorn.
