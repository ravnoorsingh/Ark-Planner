### fastapi [^fastapi-1]

FastAPI is a modern, fast (high-performance), web framework for building APIs with Python based on standard Python type hints. It builds on Starlette for the web parts and Pydantic for the data parts.

### uvicorn [^uvicorn-1]

Uvicorn is an ASGI web server implementation for Python. It currently supports HTTP/1.1 and WebSockets.

**`uvicorn.run`**

Programmatic equivalent of the uvicorn command line interface.

```

async def app(scope, receive, send):
    ...

if __name__ == "__main__":
    uvicorn.run("main:app", port=5000, log_level="info")
```

**`uvicorn.Server.serve`**

Run server in an already running async environment.

```
import asyncio
import uvicorn

async def app(scope, receive, send):
    ...

async def main():
    config = uvicorn.Config("main:app", port=5000, log_level="info")
    server = uvicorn.Server(config)
    await server.serve()

if __name__ == "__main__":
    asyncio.run(main())
```

## Implementation

### Phase 1 — Initialize project and install dependencies

- Create a project directory and navigate into it.
- Add FastAPI with standard extras using `uv add "fastapi[standard]"`[^fastapi-1].
- Add Uvicorn as the ASGI server with `uv add uvicorn`[^uvicorn-1].

### Phase 2 — Scaffold FastAPI application

- Create `app/main.py`.
- Import `FastAPI` and instantiate `app = FastAPI()`[^fastapi-1].
- Add a health‑check endpoint:
  ```python
  @app.get("/health")
  def health():
      return {"status": "ok"}
  ```[^fastapi-1]
- Import `uvicorn` and add a runnable block:
  ```python
  if __name__ == "__main__":
      uvicorn.run("app.main:app", port=8000, log_level="info")
  ```[^uvicorn-1]

### Phase 3 — Define Pydantic data models

- Create `app/schemas.py`.
- Define a `User` model inheriting from `BaseModel` with fields `name: str` and `age: int`:
  ```python
  from pydantic import BaseModel

  class User(BaseModel):
      name: str
      age: int
  ```[^pydantic-1]

### Phase 4 — Implement CRUD routes using models

- In `app/main.py`, import `User` from `app.schemas`.
- Add a POST endpoint to create a user, letting FastAPI validate the body:
  ```python
  @app.post("/users")
  def create_user(user: User):
      return user
  ```[^fastapi-1][^pydantic-1]
- Add a GET endpoint to retrieve a user by ID (placeholder implementation):
  ```python
  @app.get("/users/{user_id}")
  def read_user(user_id: int):
      return {"user_id": user_id, "name": "John Doe", "age": 30}
  ```[^fastapi-1]

### Phase 5 — Run and verify in development mode

- Start the development server with `uv run fastapi dev`[^fastapi-1].
- Open `http://127.0.0.1:8000/docs` to confirm OpenAPI UI shows the defined routes.
- Use `curl` or HTTP client to POST a JSON user and verify validation errors are returned for malformed data.

### Phase 6 — Prepare production execution

- Replace the dev command with `uv run fastapi run` for production deployment[^fastapi-1].
- Ensure the `if __name__ == "__main__"` block remains for direct `python -m app.main` execution, which uses Uvicorn under the hood[^uvicorn-1].
- Optionally configure Uvicorn settings via `uvicorn.Config` if custom options are needed (e.g., workers).

## Pitfalls

- Quote the `fastapi[standard]` extra when using `uv add` to avoid shell parsing errors[^fastapi-1].
- Define route functions with `async def` only when using `await` inside; otherwise use regular `def` to avoid unnecessary coroutine overhead[^fastapi-1].
- The `uvicorn.workers.UvicornWorker` module is deprecated; do not rely on it for production deployments[^uvicorn-1].
- Running `uv run fastapi dev` enables auto‑reload, which is unsuitable for production; switch to `fastapi run` before release[^fastapi-1].
- If you later need Gunicorn, install the separate `uvicorn-worker` package as the deprecated worker class is removed[^uvicorn-1].
- Pydantic models validate input automatically; forgetting to annotate request bodies with the model will bypass validation and may cause runtime errors[^pydantic-1].
