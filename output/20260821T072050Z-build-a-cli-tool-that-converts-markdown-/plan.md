### click [^click-1] [^click-2]

Click is a Python package for creating beautiful command line interfaces in a composable way with as little code as necessary. It’s the “Command Line Interface Creation Kit”. It aims to make the process of writing command line tools quick and fun while also preventing any frustration caused by the inability to implement an intended CLI API.

**`click.command()`**

```
import click

@click.command()
@click.option('--count', default=1, help='Number of greetings.')
@click.option('--name', prompt='Your name',
              help='The person to greet.')
def hello(count, name):    """Simple program that greets NAME for a total of COUNT times."""
    for x in range(count):
        click.echo(f"Hello {name}!")

if __name__ == '__main__':
    hello()
```

## Pitfalls

- WeasyPrint requires Python 3.10+; using older versions will cause import errors.
- WeasyPrint's public API may change without notice, potentially breaking `HTML` usage.
- Passing multiple inputs to `HTML` raises an error; ensure only one HTML string is supplied.
- The markdown library's exact conversion function is not specified in the brief; verify the correct API.
- Click option parsing can misinterpret file paths containing spaces; quote arguments when invoking.
- Large markdown files may consume significant memory when held as a single string.
