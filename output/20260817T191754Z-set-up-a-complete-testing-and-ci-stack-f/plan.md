### pytest [^pytest-1] [^pytest-2] [^pytest-3]

pytest is a Python testing framework that automatically discovers and runs test files and functions. It enhances the built‑in assert statement with advanced introspection and provides powerful fixtures and plugins for test setup and teardown.

**`pytest.__version__`**

The current pytest version, as a string:

```
>>> import pytest>>> pytest.__version__'9.0.2'
```

**`pytest.HIDDEN_PARAM`**

Added in version 8.4. Can be passed to ids of Metafunc.parametrize or to id of pytest.param to hide a parameter set from the test name. Can only be used at most 1 time, as test names need to be unique.

**`pytest.version_tuple`**

Added in version 7.0. The current pytest version, as a tuple:

```
>>> import pytest>>> pytest.version_tuple(7, 0, 0)
```

**`approx ( *expected* , *rel = None* , *abs = None* , *nan_ok = False* )`**

Assert that two numbers (or two ordered sequences of numbers) are equal to each other within some tolerance.

```
>>> from pytest import approx>>> 0.1 + 0.2 == approx(0.3)True
>>> (0.1 + 0.2, 0.2 + 0.4) == approx((0.3, 0.6))True
>>> import numpy as np>>> np.array([0.1, 0.2]) + np.array([0.2, 0.4]) == approx(np.array([0.3, 0.6]))True
```

### hypothesis [^hypothesis-1] [^hypothesis-2]

Hypothesis is the property‑based testing library for Python. With Hypothesis you write tests that should pass for all inputs in the ranges you describe, and Hypothesis randomly chooses which inputs to check – including edge cases you might not have thought about.

**`hypothesis.given`**

Standard entrypoint to Hypothesis; takes a strategy describing the type of inputs.

```
# contents of example.pyfrom hypothesis import given, strategies as st

@given(st.integers())def test_integers(n):
    print(f"called with {n}")
    assert isinstance(n, int)

test_integers()
```

**`hypothesis.assume`**

Discard test cases with false‑y arguments.

```
@given(st.integers(), st.integers())def test_integers(n1, n2):
    assume(n1 != n2)
    # n1 and n2 are guaranteed to be different here
```

**`hypothesis.strategies.filter`**

Filter generated values using a predicate.

```
@given(st.integers().filter(lambda n: n % 2 == 0))def test_integers(n):
    assert n % 2 == 0
```

**`hypothesis.settings.max_examples`**

Control the number of generated examples (default 100).

## Pitfalls

- Make sure to put "fastapi[standard]" in quotes when adding with uv to ensure it works in all terminals.
- The `fastapi dev` command automatically reads your `main.py` file, detects the FastAPI app, and starts a server with auto‑reload enabled for local development.
- If your code uses `async`/`await`, define route handlers with `async def` as shown in the async example.
- You need to have `uv` installed first before adding FastAPI with `uv add`.
- HIDDEN_PARAM can be used at most once per test session.
- approx only supports ordered sequences; sets and other unordered collections are not supported.
- version_tuple was added in version 7.0, HIDDEN_PARAM was added in version 8.4.
- Python 3.9+ is required.
- The command line client is an optional dependency; install with `httpx[cli]`.
- HTTP/2 support requires the extra `httpx[http2]`.
- Brotli and zstandard decoder support requires the extras `httpx[brotli,zstd]`.
- Test classes subclassing unittest are not supported; use unittest.IsolatedAsyncioTestCase or an async framework such as asynctest.
- Upgrading from pytest-cov 6.3: the .pth file used for subprocess measurements was removed in pytest-cov 7; use coverage's patch options instead.
- Uninstalling may leave stray .pth files: pytest-cov 2.0 may leave a pytest-cov.pth, and pytest-cov 1.8 or older may leave an init_cov_core.pth.
- For distributed testing the workers must have the pytest-cov package installed so the plugin can be registered through setuptools.
- By default, Hypothesis generates 100 random inputs; you can control this with the max_examples setting.
- SQLAlchemy and psycopg are no longer dependencies of the testcontainers[postgres] extra; you must declare them yourself if you use them.
- Version 4.0.0 onwards the legacy testcontainers-* packages are not supported; install via extras instead (e.g., pip install testcontainers[postgres]).
- The environment variable TESTCONTAINERS_HOST_OVERRIDE can be used to manually specify the Docker host IP.
- Community modules are best‑effort and may introduce breaking changes without a major version bump.
