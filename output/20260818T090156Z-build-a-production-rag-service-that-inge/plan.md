}

## Pitfalls

- Make sure to put "fastapi[standard]" in quotes when using uv add.
- Install uv first before adding FastAPI.
- If your code uses async/await, define endpoints with async def.
- fastapi dev enables auto-reload by default; for production use fastapi run.
- fastapi dev automatically reads your main.py file and detects the FastAPI app.
- Never edit `/build` directly; it is generated and should not be modified manually.
- Jupyter notebooks (`.ipynb`) are not recommended for new content in the documentation repository.
- Snippets undergo special link preprocessing; be careful about path segments when writing links in snippets.
- Each OpenAI SDK automatically reads your API key from the system environment.
- Never expose your API key in client‑side code; keep it secret and load it from an environment variable.
- Keep the total size of request headers under 64 KiB; individual custom header values should be 60 KiB or less, otherwise requests may fail before reaching the API.
- Revocations of an API key take effect within a few seconds, but other authentication updates may take up to 15 minutes to propagate.
- Extracting the text of a page can require a large amount of memory; consider checking len(page.get_contents().get_data()) beforehand to avoid OOM errors.
- If a PDF page consists only of an image (e.g., a scanned document), the extracted text may be minimal; use OCR software such as Tesseract for image‑based PDFs.
- Pydantic V2 is a ground‑up rewrite with breaking changes compared to V1; you can import V1 compatibility layer via `from pydantic import v1 as pydantic_v1`.
- Upgrade installation uses `pip install -U pydantic` or `conda install pydantic -c conda-forge`.
- Pydantic V2 requires Python 3.9+ (or 3.10+ as noted in source 3).
- The `uvicorn.workers` module is deprecated and will be removed in a future release.
